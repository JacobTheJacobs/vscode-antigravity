# Support

For bugs and feature requests, use GitHub Issues:

https://github.com/JacobTheJacobs/vscode-antigravity/issues

Before filing an issue, include:

- Extension version.
- VS Code version.
- Operating system.
- Antigravity CLI version, if available.
- What you expected.
- What happened instead.
- Screenshots or logs with secrets removed.

This is an unofficial extension and is not affiliated with Google, Microsoft,
or GitHub.
