# Code of Conduct

This project expects professional, respectful collaboration.

## Expected Behavior

- Be direct and constructive.
- Stay focused on the issue or pull request.
- Assume good faith, but keep technical claims grounded.
- Respect maintainers' time and decisions.

## Unacceptable Behavior

- Harassment, abuse, threats, or discrimination.
- Posting private information, secrets, logs, or prompts without consent.
- Spam, low-effort pile-ons, or unrelated promotion.
- Repeatedly reopening the same argument after a decision is made.

Maintainers may edit, hide, lock, or remove comments and issues that violate
these expectations.
